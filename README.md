# Apocalypter World Generation

A public guide to Apocalypter's world generation, encounters, persistence, roads, and distance cleanup, based on the observed installed game build.

Read the guide: https://DeonUrist.github.io/ApocalypterWorld/

The site is a static HTML document. `index.html` includes its styling and interactive controls; `graph-summary.txt` and `extracted/` provide the supporting files linked from the guide.

GitHub Pages publishes the root of the `main` branch. To update the guide, edit `index.html` and push to `main`.
